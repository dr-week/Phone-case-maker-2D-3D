# CaseForm Blender setup

1. In Blender, open **Edit → Preferences → Add-ons**.
2. Choose **Install…** and select `public/caseform-blender-addon.zip`.
3. Enable **Object: CaseForm Live Bridge**.
4. Keep Blender open, generate the case in CaseForm, then click **Open in Blender**.

The add-on listens only on `127.0.0.1:9025`, so it is accessible from this computer only. Its status is visible in **3D Viewport → Sidebar → CaseForm**.
